# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/274f8d67-9a1e-4f7e-ae33-292dfa350a7e

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and set the values you need, including `GEMINI_API_KEY`, `ADMIN_PIN`, and `ADMIN_EMAILS`
3. Run the app:
   `npm run dev`
